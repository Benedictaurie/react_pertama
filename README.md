# TRPL 25 - BAB II - Frontend Programming with React & Tailwind CSS

## Fitur Utama
- **Project Setup:** Inisialisasi dan konfigurasi proyek React.
- **Tailwind Integration:** Instalasi, penataan direktif CSS, dan integrasi penuh Tailwind CSS untuk desain responsif.
- **Modular Components & Layouts:** Pembuatan komponen UI terpisah, pembagian tata letak (*layouts*), dan struktur halaman (*pages*).
- **Client-Side Routing:** Navigasi antar halaman secara dinamis dan efisien menggunakan `react-router-dom`.

## Tech Stack
- **Framework / Library:** React.js
- **Styling:** Tailwind CSS
- **Routing:** React Router (`react-router-dom`)
- **Build Tool:** Vite / Node.js

## Instalasi
1. Instalasi Project React: 
`npm create vite@latest react-pertama -- --template react`
2. Instalasi Tailwind CSS: 
`cd react-pertama`
`cd react-pertama`
3. Install dependencies: `npm install`
4. Jalankan server lokal: `npm run dev`
